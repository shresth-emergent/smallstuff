# GitHub PR Focus Privacy Policy

Effective date: August 6, 2026

GitHub PR Focus helps users review GitHub pull requests by classifying the files
and changed lines visible on a pull-request diff page.

## Data processed

The extension processes the visible GitHub diff locally in the browser to
identify filenames, changed lines, and source-code comments. This processing is
necessary to calculate category totals and hide categories the user has not
selected.

The extension stores only the names of the user's selected focus categories in
Chrome Sync. It does not store pull-request content, filenames, source code,
comments, URLs, repository names, or line counts.

## Data collection and sharing

The extension does not transmit data to the developer or any third party. It
does not include analytics, advertising, tracking, remote code, or external
network requests. No user data is sold or used for advertising,
creditworthiness, or any purpose unrelated to the extension's single purpose.

Chrome Sync is provided by Google and is subject to the user's Chrome and Google
account settings.

## Retention and deletion

Pull-request content is processed only in the current page and is not retained
by the extension. Users can remove the saved category preference by clearing the
extension's site data or uninstalling the extension.

## Changes

If this policy changes, the effective date above will be updated before the
changed data practice is released.

## Contact

For questions about this policy, contact the extension publisher through the
support contact shown on its Chrome Web Store listing.
